# Kaffeemaschinen – LHI Campus Pullach

Öffentliches, mobil optimiertes Formular für die Vor-Ort-Bestandsaufnahme.

GitHub Pages leitet auf die öffentliche Formularanwendung weiter. Entwürfe
bleiben zunächst im Browser des verwendeten Geräts. Ein geführter Ablauf führt
über „Person“, „Maschinen“ und „Prüfen & speichern“. Erst im letzten Schritt
werden die vollständige Bestandsaufnahme und die den Maschinen zugeordneten
Anlagenfotos zentral gespeichert. Der CSV-Export dient nur als optionale
Sicherung.
